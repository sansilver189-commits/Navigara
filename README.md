# Navigara cold-calling dashboard

A private sales tool that runs on your Mac: import leads (e.g. from Apollo), score who is worth
calling, call them from the browser through Twilio, and track every result.

**Start here: [SETUP.md](SETUP.md)** - how to start it, back it up, where settings live, what to do
when something fails, and the cold-calling rules.

Quick start (in VS Code's terminal): `./practice.command` to try it with made-up data,
`./start.command` for the real thing.
